# 心语回响 (HeartEcho)

> **作者**：`stringkilo777`  
> **适用环境**：安卓 **Tauri Tavern** 客户端 & PC 标准版 **SillyTavern** 双端通用

一款专为**长线剧情控、掉马文学、追妻火葬场、末世/无限流智斗**打造的轻量级纯前端心智与逻辑记忆扩展。拒绝冷冰冰的派出所笔录式流水账与死板好感百分比，让角色在保留性格底色的前提下产生细腻的情感微变与宿命回响。

## 核心特性

1. **双生心智与防复读机破局锁**：
   - 废除死板的 `99.99%` 好感度数值，记录角色的**性格底色微变、嘴上态度 vs 身体下意识双标、灵魂重影与关键原话台词**，外加第一人称直白**潜台词心声**。
   - 内置**User态度备注卡（带防读心隔离声明）**与**火葬场破局行动锁**，专治 AI 口头挡刀（“冲我来/一起死”）的道德复读机毛病。
2. **掉马四档变速箱 & 防吃书物理钢印**：
   - 一键切换 `①潜伏档` / `②重影恍惚档` / `③违和试探档` / `④掉马引爆档`，解决伏笔生硬提前引爆或死都不爆的痛点。
   - 独立**不可逆物理/战力/伤病黑名单**，严禁 AI 篡改已治愈旧伤卖惨或战力崩坏。
3. **自由勾选分幕合并 & 切口现场快照**：
   - 支持自由勾选任意几幕卷宗浓缩合并，初见名场面可永久保留，告别“全部一锅乱炖”。
   - 专门提炼最后几楼的**当时情况、空气氛围、当下衣着与身体微状态**，隐藏上百楼前文依然丝滑接戏。
4. **四种投喂模式 + 第 0 楼开场白三明治保护**：
   - 支持「后台静默注入」「美化折叠块插入当前聊天楼层（自带防双倍扣费锁与一键隐藏旧楼）」「纯仓库模式」「一键复制世界书格式」。
   - 配备**跨窗口角色记忆总书架**与**最近 5 档后悔药一键回退**。

## 安装方法

### 方式一：通过 GitHub 链接安装
在酒馆顶部进入「扩展 (Extensions)」→「安装扩展 (Install Extension)」，填入本仓库的 GitHub URL 即可。

### 方式二：手动放入目录（安卓 Tauri Tavern / PC）
将整个 `heart-echo` 文件夹放入以下运行目录后，**彻底重启酒馆**并在「设置 → 扩展」中启用：
- **安卓 Tauri Tavern**：`/storage/emulated/0/Android/data/com.tauritavern.client/data/extensions/third-party/heart-echo/`
- **PC 标准版酒馆**：`SillyTavern/data/<你的用户名>/extensions/third-party/heart-echo/`
